# Builder page for Hack Club Pixl

I built this page for ([Hack Club](https://hackclub.com)) [Pixl](https://pixl.hackclub.com).

This page is designed to look like a status page of all my projects, including screenshots.

This happens to be more up to date than my main website, including new stuff like my mod "Heed The Light"

This was built using Typescript, React, Bun, and Vite.

Hosted on cloudflare pages.

  ## Konami Code

  You can enter the Konami code "↑ ↑ ↓ ↓ ← → ← → B A" to cause the website to start failing and falling apart.

  <img width="1862" height="1036" alt="image" src="https://github.com/user-attachments/assets/22b4b15c-aea0-4614-bcda-08948a5b7761" />


  ## Terminal

  If you press "`/~" you can open a secret little terminal, allowing you to change the page a little bit, and fix the aftermath of the Konami code.
